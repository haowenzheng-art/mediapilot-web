---

## 1. 概述

MediaPilot 是一个新媒体内容创作工具，核心工作流为「发现热点 → 生成文案/脚本 → 制作视频 → 发布内容」。

V1.x 版本经历了快速迭代，积累了大量业务功能，但也暴露出若干工程层面的结构性问题：硬编码配置、同步阻塞 LLM 调用、路由未拆分、无数据库迁移、无任务队列、认证后门散落各处。

本次 v2.0 重构围绕 **工程基座 + 异步体系 + Agent 架构** 三条主线展开，共经历 **三阶段 8 个任务**，涉及 **82 个文件变更**（+2336 / -787 行），最终提交 `5e12ba5`。

## 3. 三阶段执行详情

### 阶段一：工程基座加固（Task 2-4）

**目标**: 消除硬编码、建立配置管理、数据库迁移、安全中间件

#### Task 2 — 配置管理统一

| 项目 | 详情 |
|------|------|
| 修改文件 | `backend/config/settings.py` (+132 / -50) |
| 关键技术 | `pydantic_settings.BaseSettings`、`env_file` 自动加载、`extra="ignore"` 容错 |
| 核心决策 | 废弃 `os.getenv()`，所有配置走 `settings.XXX`；保留 `ensure_dev_user()` 和兼容函数 |

**关键改动**:
- `class Settings(BaseSettings)` 替代旧 `class Settings`（纯数据类）
- 新增 `DEV_MODE`、`CORS_ORIGINS`、`RATE_LIMIT_ENABLED`、`REDIS_URL` 等配置项
- `ensure_dev_user(db)` 作为统一认证门控，DEV_MODE=False 时抛 401

#### Task 3 — 数据库迁移

| 项目 | 详情 |
|------|------|
| 新建文件 | `backend/alembic.ini`、`alembic/env.py`、`alembic/script.py.mako` |
| 迁移文件 | `95e4b7d794d8_initial_migration.py`（8 张表）、`3a016db24d47_add_copywriting_table.py` |
| 新建模型 | `backend/models/database/copywriting.py`（CopywritingTable） |
| 新建仓库 | `backend/repository/copywriting_repo.py` |
| 修改文件 | `backend/models/database/base.py`、`tables.py`、`__init__.py` |
| 关键技术 | Alembic autogenerate 不支持 SQLite 的 CREATE TABLE，手动编写初始迁移 |

**关键决策**:
- `alembic.ini` 中 `sqlalchemy.url` 留空，由 `env.py` 从环境变量读取 `DATABASE_URL`
- SQLite 环境下 `batch_alter_table` 处理 ALTER 操作
- 初始迁移手写（非 autogenerate），包含全部 8 张表的 CREATE TABLE

#### Task 4 — 中间件与安全

| 项目 | 详情 |
|------|------|
| 修改文件 | `backend/main.py`（CORS 条件化）、`backend/api/__init__.py`（DEV_MODE 控制限流） |
| 修改路由 | `trending.py`、`subscription.py`、`copywriting.py`、`shoot_script.py`、`content_library.py` |
| 关键技术 | `ensure_dev_user()` 统一替换 `settings.get_dev_user()` |

---

### 阶段二：异步化改造（Task 5-6）

**目标**: 消除事件循环阻塞、引入任务队列

#### Task 5 — LLM 调用异步化

| 项目 | 详情 |
|------|------|
| 修改核心 | `backend/core/ai_service.py`（-1 time import, +asyncio.to_thread） |
| 修改服务 | `copywriting_service.py`（删同步方法）、`shoot_script_service.py`（async） |
| 修改服务 | `content_service.py`、`media_service.py` |
| 修改路由 | `api/copywriting.py`、`api/content.py`、`api/routes.py`、`api/ai_chat.py`、`api/video.py`、`api/trending.py`、`api/shoot_script.py` |
| 总计 | **12 个文件**，全部改为 `await` |

**关键改动**:
- `AIService.generate()` 从 `def` 改为 `async def`
- `AnthropicService.generate()` / `OpenAIService.generate()` / `ArkService.generate()` 全部使用 `asyncio.to_thread()` 包装同步客户端
- `AIServiceManager.generate()` + 3 个辅助方法（`generate_content_script`、`rewrite_transcript`、`generate_outline`）改为 async
- `copywriting_service.py` 删除 `generate()` 同步方法和 `_sync_generate_or_mock_*` 系列方法

#### Task 6 — 任务队列（ARQ + Redis）

| 项目 | 详情 |
|------|------|
| 新建 | `backend/worker.py`（ARQ Worker 入口 + 2 个 job 函数） |
| 新建 | `backend/api/task_queue.py`（POST /tasks/submit, GET /tasks/{task_id}, GET /tasks/history） |
| 修改 | `docker-compose.yml`（新增 Redis 服务 + depends_on） |
| 修改 | `backend/requirements.txt`（arq>=0.23.0, redis>=4.5.0） |
| 修改 | `backend/config/settings.py`（REDIS_URL 配置项） |
| 修改 | `backend/main.py`（arq_pool 全局变量 + Redis 连接池初始化） |
| 修改 | `backend/repository/task_repo.py`（新增 create/update 方法） |
| 修改 | `backend/api/__init__.py`（注册 task_queue_router） |

**任务流**:
```
API POST /tasks/submit → arq_pool.enqueue_job() → Redis 队列
                                           ↓
                                    ARQ Worker 拉取
                                           ↓
                                    Job 函数执行 → 写 TaskTable → 返回结果
                                           ↓
                              API GET /tasks/{task_id} → arq_pool.ainfo_job()
```

## 4. 架构演进对比

| 维度 | V1.x (7d87a54) | V2.0 (5e12ba5) |
|------|----------------|----------------|
| **配置管理** | `os.getenv()` 散落在 10+ 处，`.env` 手动 `load_dotenv()` | `pydantic-settings BaseSettings` 单一来源，自动加载 |
| **路径管理** | `sys.path.insert(0, project_root)` 硬编码 | 标准 `backend.` 前缀导入，移除 path hack |
| **数据库** | `init_db()` 直接建表，无迁移工具 | Alembic + 初始迁移 + copywriting 增量迁移 |
| **CORS** | 硬编码 `["*"]` | `CORS_ORIGINS` 环境变量 + DEV_MODE 开关 |
| **速率限制** | 无条件注册 | `RATE_LIMIT_ENABLED` + `DEV_MODE` 条件注册 |
| **认证门控** | 5 个路由文件各自 `settings.get_dev_user()` | 统一 `ensure_dev_user(db)` 一处定义 |
| **LLM 调用** | 全部同步阻塞（`client.messages.create()`） | 全部 `async def` + `asyncio.to_thread()` 非阻塞 |
| **事件循环** | 12+ 处 `ai_manager.generate()` 未被 await | 全部改为 `await`，零阻塞残留 |
| **任务调度** | 内存 `Dict` 存储，进程重启丢失 | ARQ + Redis 持久化队列 |
| **Agent** | 无 | Tool 抽象层 + ReAct 执行器 + 3 个预置工具 |
| **Docker** | 仅 backend + frontend | + redis（healthcheck + 持久化卷） |
| **代码规模** | 19970 行 | +2336 / -787 = 净增 1549 行 |
| **文件变更** | — | 82 个文件 |
